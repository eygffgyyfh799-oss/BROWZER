# jinn

سكربت FiveM يحولك **جني**. كله شكل ومؤثرات، وما يضر أي لاعب ثاني.

## التركيب
1. انسخ مجلد `jinn` إلى `resources`.
2. أضف في `server.cfg`:
   ```cfg
   ensure jinn
   add_ace group.admin command.jinn allow
   ```

## الاستخدام
اكتب `/jinn` عشان تتحول جني، واكتبه مرة ثانية عشان ترجع طبيعي.

| الزر | القدرة |
|---|---|
| `X` | طيران (W/A/S/D للحركة، Space فوق، Ctrl تحت، Shift أسرع)، وتعدي من الجدران |
| `E` | انتقال سريع لقدام وسط دخان |
| `G` | اختفاء (الباقين ما يشوفونك، وانت تشوف نفسك شفاف) |
| `H` | صرخة الجني: دخان ونار، واللي حولك تهتز شاشتهم ويطلع لهم فلتر |

كل لاعب يقدر يغير الأزرار من: الإعدادات > Key Bindings > FiveM.

## شكل الجني
- جسم شفاف مثل الشبح
- دخان أسود يطلع منه
- عيون نار
- توهج أحمر حوله
- دخان وصوت وقت التحول
- فلتر أحمر على شاشتك
- ما يتأذى، ويركض ويقفز أسرع

كل شي يتعدل من `config.lua`.
لو نار العيون طلعت بعيد عن العيون عدل `EyeOffset`.
