# always_snow

جو ثلج دايم لكل اللاعبين: ثلج يطيح، أرض بيضا، آثار أقدام وكفرات، وصوت المشي على الثلج.

## التركيب
1. انسخ مجلد `always_snow` إلى `resources`.
2. في `server.cfg` (بعد سكربت الطقس):
   ```cfg
   ensure always_snow
   ```

## بدون تعارض
- ما يوقف سكربت الطقس، يخليه هو نفسه يطبق الثلج (qb-weathersync، qbx، vSync، Renewed-Weathersync)
- أي سكربت طقس ثاني: فحص خفيف يرجع الثلج بس لو الجو تغير
- الوقت ما يتغير، يبقى نفس وقت السيرفر
- يوقف نفسه مؤقتاً لما تكون المدينة محروقة (missile_city) أو وقت فلم النووي، أو للي في العالم الثلجي (snow_world)، ويرجع بعدها

## الإعدادات (`config.lua`)
- `Weather`: `XMAS` (الأفضل) أو `SNOWLIGHT` أو `BLIZZARD`
- الأرض البيضا، آثار الأقدام، صوت المشي على الثلج
