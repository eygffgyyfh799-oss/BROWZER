# snow_world — العالم الثلجي

سكربت FiveM يسوي **عالم ثاني ثلجي**: نفس المدينة بس كلها ثلج، وشكل **مدينة خربانة بشكل بسيط**، ومنفصل **بالكامل** عن العالم العادي.

## الأمان على العالم الأساسي
- كل الخراب (سيارات محروقة، ركام، دخان) **محلي**: ينرسم بس على شاشة اللي داخل العالم، وما ينشاف ولا يتزامن مع أحد، وما يغير أي شي حقيقي في المدينة.
- الطقس والوقت والفلاتر تتغير **بس** عند اللي داخل العالم.
- العالم العادي ما يتغير فيه أي شي.

## التركيب
1. احذف مجلد `snow_world` القديم وحط الجديد مكانه.
2. في `server.cfg`:
   ```cfg
   ensure oxmysql        # قبل snow_world (لو عندك)
   ensure pma-voice      # قبل snow_world (لو عندك)
   ensure snow_world
   ```
3. الجدول `world_members` ينسوى **تلقائياً** في قاعدة البيانات. لو ما عندك oxmysql يحفظ في `members.json`.

## مين يقدر يستخدم الأوامر
**أي أدمن**:
- QBCore / Qbox: صلاحية `admin` أو `god`
- ESX: قروب `admin` أو `superadmin`
- أو ACE: `group.admin` (وأدمن txAdmin)

## الأوامر (برقم الهوية — متصل أو مطفي)
| الأمر | الوظيفة |
|---|---|
| `/setworld ABC12345` | ينقل صاحب رقم الهوية للعالم الثلجي ويقفل عليه |
| `/unsetworld ABC12345` | يطلعه ويرجعه للعالم العادي |
| `/worldlist` | مين في العالم الثلجي، ومين متصل الحين |
| `/checkworld ABC12345` | وين مسجل |

- لو اللاعب **متصل** ينتقل على طول، ولو **مطفي** يدخل العالم أول ما يختار شخصيته.
- **القفل**: اللي مسجل ما يقدر يطلع أبد إلا بـ `/unsetworld` من أدمن. لو أي سكربت ثاني رجّعه للعادي، يرجع لعالمه تلقائياً.
- التسجيل على **الشخصية** (رقم الهوية)، فلو عنده شخصية ثانية غير مسجلة تكون في العالم العادي.
- ما فيه بوابات ولا أي طريقة ثانية للدخول.

## العالم الثلجي (`config.lua`)
ثلج يطيح، أرض بيضا، آثار أقدام وكفرات، ومدينة خربانة بشكل بسيط (`ruins = true`).
تقدر تطفي الخراب أو تعدل كثافته من `Config.Ruins`.

## الفصل الكامل بين العوالم
| الشي | الحالة |
|---|---|
| اللاعبين والسيارات والـ NPC | منفصلين |
| الطقس والوقت والأنوار | كل عالم له جوه |
| الصوت القريب، الراديو، المكالمات | منفصلة (pma-voice) |
| الشات، `/me` `/do` `/ooc` | توصل بس لعالمك |
| `/911` | للشرطة اللي في عالمك بس، مع تنبيه ومكان على الخريطة |
| قائمة اللاعبين (`HOME`) | بس اللي في عالمك وعدد الشرطة |
| missile_city | اللي في عالم ثاني ما يشوف الصواريخ ولا النووي |

لو عندك `/me` أو `/ooc` أو `/911` في سكربت ثاني، في `Config.ChatCommands` حط `false` للأمر.

## ربط سكربتات الشرطة والبلاغات والجوال
```lua
-- سيرفر
exports.snow_world:GetWorld(source)              -- 'main' أو 'snow' ...
exports.snow_world:IsSameWorld(a, b)
exports.snow_world:GetPlayersInWorld('snow')
exports.snow_world:GetPoliceInWorld('snow')
exports.snow_world:GetPoliceCount(source)
exports.snow_world:SendWorldDispatch(source, { title = '...', text = '...' })
exports.snow_world:TriggerWorldEvent(source, 'اسم الحدث', ...)
-- كلاينت
exports.snow_world:GetWorld()
exports.snow_world:IsInSnowWorld()
```
