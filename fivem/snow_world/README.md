# snow_world — نظام العوالم

سكربت FiveM يسوي **عوالم منفصلة** (ثلجي، رملي، ليل دائم، رعب، وتقدر تضيف غيرها).
كل عالم نفس المدينة بس بجو ووقت خاص، ومنفصل **بالكامل** عن العالم العادي وعن باقي العوالم.

## التركيب
1. احذف مجلد `snow_world` القديم وحط الجديد مكانه.
2. في `server.cfg` (نفس القديم، ما تغير شي):
   ```cfg
   ensure snow_world
   add_ace group.admin command.snowworld allow
   ```
3. لو تستخدم pma-voice خل `ensure snow_world` **بعد** `ensure pma-voice`.

## العوالم الجاهزة (`config.lua`)
| المفتاح | العالم | الجو |
|---|---|---|
| `snow` | ❄ العالم الثلجي | ثلج يطيح، أرض بيضا، آثار أقدام وكفرات |
| `desert` | 🏜 العالم الرملي | شمس قوية الساعة 1 الظهر وفلتر دافي |
| `night` | 🌙 عالم الليل | ليل دائم الساعة 12 |
| `horror` | 👻 عالم الرعب | ضباب رعب، أنوار المدينة طافية، فلتر أحمر، بدون ناس |

تقدر تضيف عالم جديد بنسخ أي واحد وتغيير `bucket` (لازم رقم مختلف).

## الأوامر (للأدمن)
| الأمر | الوظيفة |
|---|---|
| `/world 12 snow` | ينقل اللاعب 12 للعالم الثلجي (`main` = العادي) |
| `/world desert` | ينقلك انت |
| `/world 12` | يقول لك اللاعب 12 في أي عالم |
| `/worlds` | كل العوالم ومين فيها |
| `/worldall` أو `/worldall snow` | يرجع الكل (أو كل اللي في عالم معين) للعادي |
| `/portal add snow` | يحط بوابة في مكانك |
| `/portal del` | يحذف أقرب بوابة |
| `/portal list` | قائمة البوابات |
| `/snow [آيدي]` و `/unsnow [آيدي]` | مثل قبل |

## البوابات
- دائرة على الأرض، توقف فيها يطلع لك **"اضغط E للدخول إلى ..."**
- نفس البوابة داخل العالم ترجعك للعالم العادي
- تنحفظ تلقائياً في `portals.json`، أو تحطها ثابتة في `Config.Portals`
- تقدر تقفل بوابة على صلاحية: `/portal add snow vip.access`

## الحفظ
اللاعب يرجع لنفس عالمه لو طلع من السيرفر ورجع (بعد ما يختار شخصيته).
ولو سكربت ثاني رجّعه للعالم العادي (مثلاً طلع من شقة) يرجع لعالمه تلقائياً.

## الفصل الكامل بين العوالم
| الشي | الحالة |
|---|---|
| اللاعبين والسيارات والـ NPC | منفصلين |
| الطقس والوقت والأنوار | كل عالم له جوه، والعالم العادي ما يتأثر |
| الصوت القريب | منفصل (pma-voice) |
| موجات الراديو | موجة 1 في كل عالم غير موجة 1 في الثاني |
| مكالمات الجوال الصوتية | ما يسمع اللي في عالم ثاني |
| الشات العادي | يوصل بس لعالمك |
| `/me` `/do` `/ooc` | توصل بس لعالمك |
| `/911` | يوصل بس للشرطة اللي في عالمك، مع تنبيه ومكان على الخريطة |
| قائمة اللاعبين (`HOME`) | تعرض بس اللي في عالمك وعدد الشرطة |
| missile_city | اللي في عالم ثاني ما يشوف الصواريخ ولا النووي |

## الطقس والوقت بدون تعارض
السكربت ما يوقف سكربت الطقس عندك، يخليه هو نفسه يطبق جو العالم.
يدعم: **qb-weathersync، qbx، vSync، Renewed-Weathersync**، وأي سكربت ثاني فيه حماية تلقائية.

## لو عندك نفس الأوامر في سكربت ثاني
لو عندك `/me` أو `/ooc` أو `/911` في سكربت ثاني، في `Config.ChatCommands` حط `false` للأمر أو غير اسمه.

## ربط سكربتات الشرطة والبلاغات والجوال
```lua
-- سيرفر
exports.snow_world:GetWorld(source)              -- 'main' أو 'snow' ...
exports.snow_world:SetWorld(source, 'snow')
exports.snow_world:IsSameWorld(a, b)
exports.snow_world:GetPlayersInWorld('snow')
exports.snow_world:GetPoliceInWorld('snow')
exports.snow_world:GetPoliceCount(source)         -- عدد الشرطة في عالم اللاعب
exports.snow_world:SendWorldDispatch(source, { title = '...', text = '...' })
exports.snow_world:TriggerWorldEvent(source, 'اسم الحدث', ...)
-- كلاينت
exports.snow_world:GetWorld()
exports.snow_world:IsInSnowWorld()               -- true لو في أي عالم غير العادي
```
