# snow_world

سكربت FiveM يسوي **عالم ثاني ثلجي**. تنقل أي لاعب له بأمر، فيشوف نفس المدينة بس كلها ثلج، وينفصل عن باقي اللاعبين بالكامل.

- اللي داخل العالم الثلجي: يشوف ثلج يطيح وأرض بيضا وآثار أقدام وكفرات، ويشوف **بس** اللاعبين اللي معه في نفس العالم
- اللاعبين العاديين: ما يشوفون الثلج ولا يشوفون اللي داخل العالم الثلجي، ولا يقدرون يتفاعلون معهم أبد
- الفصل كامل لأنه يستخدم Routing Buckets من FiveM: لاعبين، سيارات، أصوات، كل شي منفصل

## التركيب
1. انسخ مجلد `snow_world` إلى `resources`.
2. أضف في `server.cfg`:
   ```cfg
   ensure snow_world
   add_ace group.admin command.snowworld allow
   ```

## الأوامر
| الأمر | الوظيفة |
|---|---|
| `/snow [آيدي]` | ينقل اللاعب للعالم الثلجي (بدون آيدي = انت) |
| `/unsnow [آيدي]` | يرجع اللاعب للعالم العادي (بدون آيدي = انت) |
| `/snowlist` | يعرض مين داخل العالم الثلجي |
| `/unsnowall` | يرجع الكل للعالم العادي |

لو اللاعب سايق سيارة ولحاله فيها، السيارة تنتقل معه.
لو طلع من السيرفر ورجع يرجع للعالم العادي تلقائياً.

## الإعدادات (`config.lua`)
- رقم العالم `Bucket`
- وجود ناس وسيارات NPC في العالم الثلجي `Population`
- نوع الطقس، آثار الأقدام، فلتر إضافي، ونصوص الرسائل
