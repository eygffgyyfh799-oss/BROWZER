# AI Video Upscaler & Enhancer Pro

أداة سطر أوامر (CMD) مع واجهة ويب بسيطة لتحسين جودة المقاطع: رفع الدقة إلى **1080p / 4K**، إزالة التشويش وتقطّع الضغط، تصحيح الألوان، زيادة الحدة، ورفع معدل الإطارات إلى **30 / 60fps**. الناتج ملف **MP4** (H.264 + AAC) جاهز للتحميل.

## المتطلبات
- **Python 3.9+** (بدون مكتبات إضافية)
- **FFmpeg** مضاف إلى PATH ([تحميل](https://ffmpeg.org/download.html)). على ويندوز: `winget install ffmpeg`
- (اختياري) **Real-ESRGAN** لتكبير الإطارات بالذكاء الاصطناعي في وضع Pro: حمّل `realesrgan-ncnn-vulkan` من [صفحة الإصدارات](https://github.com/xinntao/Real-ESRGAN/releases) وضعه مع مجلد `models` داخل `bin/`، أو أضفه إلى PATH، أو حدّد المسار في المتغير `REALESRGAN_PATH`. يحتاج كرت شاشة يدعم Vulkan.

## التشغيل

### الواجهة (الطريقة الأسهل)
```
run.bat            (ويندوز - دبل كلك)
./run.sh           (لينكس / ماك)
python -m enhancer (أي نظام)
```
يفتح المتصفح تلقائياً على `http://localhost:7860`:
1. اسحب المقطع وأفلته (MP4 / MOV / WEBM)
2. اختر المحرك، الدقة، معدل الإطارات، والقالب
3. اضغط **تحسين** ثم **تحميل الفيديو المحسّن**

### سطر الأوامر
```
python -m enhancer enhance input.mp4 -r 4k -e pro -f 60 -p ugc -o output.mp4
python -m enhancer check          # فحص FFmpeg و Real-ESRGAN
python -m enhancer serve --port 8080 --no-browser
```

| الخيار | القيم | الوصف |
|---|---|---|
| `-e, --engine` | `standard`, `pro` | سريع / إعادة بناء التفاصيل |
| `-r, --resolution` | `1080p`, `4k` | الدقة المستهدفة (للضلع الأقصر، يدعم المقاطع العمودية) |
| `-f, --fps` | `original`, `30`, `60` | رفع السلاسة بـ Frame Interpolation |
| `-p, --preset` | `ai`, `old_film`, `ugc`, `none` | مقاطع الذكاء الاصطناعي / الأفلام القديمة / لقطات الهواتف / عام |
| `--crf` | رقم | جودة الترميز (أقل = أعلى جودة، الافتراضي 18 / 16) |
| `--ai` / `--no-ai` | | فرض أو تعطيل Real-ESRGAN |

## كيف تعمل المعالجة
- **الاتساق الزمني ومنع الوميض:** إزالة تشويش زمنية-مكانية (`hqdn3d` و `atadenoise`) تقارن كل إطار بما قبله وبعده، إضافة لفلتر `deflicker`، وتمرير إضافي لتنعيم الفروق بين الإطارات بعد تكبير Real-ESRGAN.
- **إزالة الضوضاء والتشوهات:** `deblock` لتقطّع الضغط، و `nlmeans` (في Pro) لحبيبات الإضاءة الضعيفة مع الحفاظ على ملمس البشرة والنصوص، ثم `gradfun` لمنع تدرّج الألوان.
- **رفع الدقة:** Lanczos عالي الدقة + حدة تكيفية `cas` (وفي Pro مع Real-ESRGAN: تكبير إطاراً بإطار بالذكاء الاصطناعي).
- **رفع معدل الإطارات:** `minterpolate` مع تعويض الحركة (Motion Compensation)، ويُطبّق قبل التكبير لتسريع المعالجة.
- **التصدير:** H.264 مع `+faststart` جاهز للتشغيل والرفع مباشرة.

> ملاحظة: بدون Real-ESRGAN يعتمد وضع Pro على فلاتر FFmpeg المتقدمة فقط، وتكون النتيجة أفضل من Standard لكن أقل من إعادة البناء بالذكاء الاصطناعي. وضع 4K و 60fps بطيئان على المعالج، خصوصاً للمقاطع الطويلة.

الملفات المؤقتة تُحفظ في `~/.video-enhancer`.
