# AI Video Upscaler & Enhancer Pro

أداة سطر أوامر (CMD) مع واجهة ويب بسيطة لتحسين جودة المقاطع: رفع الدقة إلى **1080p / 4K**، إزالة التشويش وتقطّع الضغط، تصحيح الألوان، زيادة الحدة، ورفع معدل الإطارات إلى **30 / 60fps**. الناتج ملف **MP4** (H.264 + AAC) جاهز للتحميل.

## التشغيل — بدون أي تثبيت يدوي
| النظام | طريقة التشغيل |
|---|---|
| ويندوز | دبل كلك على **`run.bat`** |
| ماك | دبل كلك على **`start-mac.command`** |
| لينكس | `./run.sh` |

**أول تشغيل** تقوم الأداة بتثبيت كل شي تحتاجه تلقائياً (مرة واحدة فقط، تقريباً 200 ميجا):
1. **Python** — إذا ما كان موجود (ويندوز: عبر winget أو من python.org مباشرة)
2. **FFmpeg** — محرك المعالجة والترميز
3. **Real-ESRGAN** — نماذج تكبير الإطارات بالذكاء الاصطناعي، وتُختبر على جهازك: إذا كرت الشاشة يدعم Vulkan يتفعّل الذكاء الاصطناعي في وضع Pro، وإذا لا تشتغل الأداة بفلاتر FFmpeg المتقدمة بدون أي خطأ.

كل الملفات تنحفظ داخل مجلد `bin/` جنب الأداة (ما يتثبت شي على مستوى النظام غير Python). بعدها يفتح المتصفح على `http://localhost:7860`:
1. اسحب المقطع وأفلته (MP4 / MOV / WEBM)
2. اختر المحرك، الدقة، معدل الإطارات، والقالب
3. اضغط **تحسين** ثم **تحميل الفيديو المحسّن**

## تسريع كرت الشاشة (NVIDIA RTX وغيرها)
عند أول تشغيل تختبر الأداة جهازك وتفعّل تلقائياً كل ما يدعمه:

| المرحلة | على كرت الشاشة | البديل إذا ما فيه دعم |
|---|---|---|
| تكبير الدقة | Real-ESRGAN (Vulkan) | فلاتر FFmpeg على المعالج |
| رفع الإطارات 30/60fps | RIFE v4.6 (Vulkan) | FFmpeg minterpolate (بطيء) |
| الترميز | NVENC (NVIDIA) | x264 على المعالج |

- المعالجة تتم على دفعات (240 إطار) حتى لا تمتلئ مساحة القرص حتى مع 4K.
- مقاطع HDR من الجوالات (iPhone / Android) تتحول تلقائياً لألوان طبيعية.
- مقاطع معدل الإطارات المتغير (VFR) تتحول لمعدل ثابت حتى يبقى الصوت متزامن.
- حدّث تعريف كرت الشاشة لآخر إصدار (مهم لكروت RTX 50).

### الإعداد المقترح لـ RTX 5060 (سرعة + جودة)
- **المحرك: Standard** — يستخدم نموذج `realesr-animevideov3` السريع على كرت الشاشة. جودة ممتازة وسرعة عالية، وهو الأنسب لأغلب المقاطع.
- **المحرك: Pro** — يستخدم `realesrgan-x4plus` لأعلى تفاصيل في اللقطات الحقيقية، وهو أبطأ بشكل ملحوظ. استخدمه للمقاطع القصيرة أو المهمة.
- **الدقة:** 1080p للسرعة، و 4K إذا كان المقطع للعرض على شاشات كبيرة.
- **FPS:** 60fps مع RIFE سريع على كرت الشاشة، لكنه يضاعف عدد الإطارات المطلوب تكبيرها، فيزيد وقت المعالجة.

### سطر الأوامر
```
python -m enhancer enhance input.mp4 -r 4k -e pro -f 60 -p ugc -o output.mp4
python -m enhancer check          # فحص FFmpeg و Real-ESRGAN
python -m enhancer setup --force  # إعادة تثبيت المكونات
python -m enhancer serve --port 8080 --no-browser
```

| الخيار | القيم | الوصف |
|---|---|---|
| `-e, --engine` | `standard`, `pro` | سريع / إعادة بناء التفاصيل |
| `-r, --resolution` | `1080p`, `4k` | الدقة المستهدفة (للضلع الأقصر، يدعم المقاطع العمودية) |
| `-f, --fps` | `original`, `30`, `60` | رفع السلاسة بـ Frame Interpolation |
| `-p, --preset` | `ai`, `old_film`, `ugc`, `none` | مقاطع الذكاء الاصطناعي / الأفلام القديمة / لقطات الهواتف / عام |
| `--crf` | رقم | جودة الترميز (أقل = أعلى جودة، الافتراضي 18 / 16) |
| `--ai` / `--no-ai` | | فرض أو تعطيل Real-ESRGAN |

## كيف تعمل المعالجة
- **الاتساق الزمني ومنع الوميض:** إزالة تشويش زمنية-مكانية (`hqdn3d` و `atadenoise`) تقارن كل إطار بما قبله وبعده، إضافة لفلتر `deflicker`، وتمرير إضافي لتنعيم الفروق بين الإطارات بعد تكبير Real-ESRGAN.
- **إزالة الضوضاء والتشوهات:** `deblock` لتقطّع الضغط، و `nlmeans` (في Pro) لحبيبات الإضاءة الضعيفة مع الحفاظ على ملمس البشرة والنصوص، ثم `gradfun` لمنع تدرّج الألوان.
- **رفع الدقة:** Lanczos عالي الدقة + حدة تكيفية `cas` (وفي Pro مع Real-ESRGAN: تكبير إطاراً بإطار بالذكاء الاصطناعي).
- **رفع معدل الإطارات:** `minterpolate` مع تعويض الحركة (Motion Compensation)، ويُطبّق قبل التكبير لتسريع المعالجة.
- **التصدير:** H.264 مع `+faststart` جاهز للتشغيل والرفع مباشرة.

> ملاحظة: إذا ما فيه كرت شاشة يدعم Vulkan يعتمد وضع Pro على فلاتر FFmpeg المتقدمة فقط، وتكون النتيجة أفضل من Standard لكن أقل من إعادة البناء بالذكاء الاصطناعي. وضع 4K و 60fps بطيئان على المعالج، خصوصاً للمقاطع الطويلة.

الملفات المؤقتة تُحفظ في `~/.video-enhancer`. إذا فشلت المعالجة بالذكاء الاصطناعي أثناء التشغيل تتحول الأداة تلقائياً لفلاتر FFmpeg وتكمل.
