# أداة الفحص والتنظيف (Security Cleaner) v2

أداة لويندوز تفحص الجهاز من الفيروسات وسارقات الباسوردات وبرامج التعدين (Miners). هذي البرامج تجي عادة مع الألعاب المكركة، أو "Steam Tools" المزيفة، أو ملفات FiveM الملغّمة. بعد الفحص تنظّف اللي تلقاه بأمان.

## الملفات

| الملف | وش يسوي |
|---|---|
| `Scan.bat` | فحص سريع، وبعده يسألك إذا تبي تنظّف |
| `Deep-Scan.bat` | **فحص كامل للجهاز** (أبطأ، بس أدق) |
| `Clean.bat` | فحص وتنظيف مباشرة |
| `Restore.bat` | يرجّع أي شيء نظّفته |

## طريقة الاستخدام

1. فك الضغط: كليك يمين على الـ zip ← **Extract All**.
2. كليك يمين على `Scan-And-Clean.ps1` ← Properties ← علّم على **Unblock** ← OK.
3. كليك يمين على **`Deep-Scan.bat`** ← **Run as administrator**.
4. إذا طلعت لك رسالة "Windows protected your PC": اضغط **More info** ← **Run anyway**.
5. في آخر الفحص يسألك إذا تبي تنظّف. اكتب `y`، وبعدها تمر على كل مشكلة: `y` نظّف، `n` تخطَّ، `a` نظّف الكل، `q` وقّف.
6. إذا لقى شيء **High** يعرض عليك **فحص Defender Offline**. هذا الفحص يعيد تشغيل الجهاز ويفحص قبل ما يشتغل ويندوز، وهو أقوى فحص موجود.
7. بعد التنظيف سوِّ ريستارت، وافحص مرة ثانية.

### خيارات إضافية (من PowerShell كمسؤول)

```powershell
.\Scan-And-Clean.ps1 -FullScan -ScanPaths "D:\Games","D:\FiveM"   # افحص مجلدات إضافية
.\Scan-And-Clean.ps1 -FullScan -Clean -AutoFixHigh                  # نظّف الـ High تلقائياً بدون ما يسألك
.\Scan-And-Clean.ps1 -OfflineScan                                   # افحص وبعدها سوِّ Offline scan
```

## وش تفحص الأداة؟

- **Windows Defender:**
  - تشوف إذا الحماية مطفية، أو فيه سياسات تضعفها، أو استثناءات، أو تهديدات مسوّي لها "Allow".
  - تفعّل حظر البرامج غير المرغوبة (PUA) والحماية السحابية.
  - تحدّث Defender وتفحص فيه.
- **برامج التعدين (Miners):**
  - أسماء برامج التعدين المعروفة (xmrig، nbminer، t-rex، lolminer...) وأوامر التشغيل حقتها.
  - ملفات الإعدادات حقتها، والاتصال بمنافذ مواقع التعدين (mining pools).
  - برامج غير موقّعة تستهلك المعالج بشكل عالي، وتعريف WinRing0.
- **برامج تنتحل اسم برامج ويندوز:** مثل `svchost` أو `explorer` شغالة من مجلد غلط، أو أسماء مزورة زي `svch0st`.
- **سكربتات مخفية شغالة:** PowerShell مشفّر (`-enc`) وأوامر تحميل من النت.
- **الأماكن اللي يثبّت فيها الفيروس نفسه عشان يرجع يشتغل:**
  - Run keys، مجلد Startup، المهام المجدولة، الخدمات، التعريفات (Drivers)
  - WMI، IFEO، Winlogon، AppInit_DLLs
  - ملفات بروفايل PowerShell
- **المتصفحات:** إضافات مثبتة بالقوة (سارقات الباسوردات والكريبتو تستخدم هالطريقة)، واختصارات فيها `--load-extension`.
- **الشبكة:** ملف hosts، البروكسي، Windows Update إذا أحد طافيه.
- **ملفات مزيفة:** مثل `صورة.jpg.exe` و `ملف.pdf.scr`.
- **Steam:** ملفات `hid.dll` و `xinput1_4.dll` وغيرها من SteamTools أو GreenLuma أو فيروس.
- **FiveM:**
  - إضافات مدسوسة في مجلد FiveM (plugins).
  - باك دور في سكربتات `.lua` و `.js`، **حتى لو الكود مخفي بتشفير** (`\x..` أو `\ddd` أو `string.char`).
  - سكربتات تسرق مفاتيح السيرفر وترسلها لويب هوك Discord.

## ضمانات الأمان: ما تخرّب النظام

- **ما تحذف أي شيء نهائياً.** الملفات تنتقل للحجر في `C:\SecurityCleaner\Quarantine`.
- **تسوي نقطة استعادة للنظام (System Restore) قبل التنظيف.**
- **تاخذ نسخة احتياطية `.reg`** قبل أي تعديل في الريجستري.
- **المهام المجدولة والخدمات توقفها بس، ما تحذفها.**
- **حماية صارمة، الأداة ما تلمس أبداً:**
  - أي شيء داخل `C:\Windows`
  - أي ملف موقّع من مايكروسوفت
  - البرامج الموقّعة في Program Files
  - جذر القرص والمجلدات الرئيسية
  - خدمات ويندوز الأساسية وعمليات النظام الحساسة
- كل شيء يرجع بـ `Restore.bat`، أو من نقطة الاستعادة: `rstrui.exe` ← اختر "SecurityCleaner".
- سجل كامل لكل شيء صار ينحفظ في `C:\SecurityCleaner\Logs`.

## مستويات الخطورة

- **High**: خطير على الأغلب. نظّفه.
- **Medium**: مشبوه. إذا تعرفه (مثلاً لعبة شغالة الحين) اكتب `n`، وإذا ما تعرفه نظّفه.
- **Info**: للعلم بس، والأداة ما تلمسه.

## ⚠️ مهم

- ما فيه أداة تقدر تضمن 100% إنها تصيد كل فيروس. إذا رجعت نتائج **High** بعد التنظيف والريستارت و Offline scan، خذ نسخة من ملفاتك وسوِّ **Reset this PC ← Remove everything**.
- سارقات الباسوردات تسرق حساباتك أول ما تشتغل، والتنظيف ما يرجّع اللي انسرق. من **جهاز ثاني نظيف** غيّر باسوردات: الإيميل، Discord، Steam، Rockstar/CFX، والبنك. وسوِّ تسجيل خروج من كل الأجهزة، وفعّل التحقق بخطوتين (2FA).
- للاطمئنان أكثر، افحص فحص ثاني بـ **Malwarebytes** أو **ESET Online Scanner**.
