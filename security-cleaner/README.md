# أداة الفحص والتنظيف (Security Cleaner)

أداة لويندوز تفحص الجهاز بعد تحميل ألعاب مكركة، أو "Steam Tools" مزيفة، أو ملفات FiveM ملغّمة، وبعدها تنظّف اللي تلقاه.

## طريقة الاستخدام

1. نزّل مجلد `security-cleaner` كامل على جهازك.
2. شغّل **`Scan.bat`**: كليك يمين ← Run as administrator.
   - الفحص **ما يغيّر أي شيء** في جهازك.
   - يحدّث Windows Defender ويسوي فحص سريع، ويفحص Downloads و Desktop و AppData و Temp.
   - التقرير ينحفظ على سطح المكتب باسم `SecurityScan_التاريخ.txt`.
3. في آخر الفحص يسألك: `Start cleaning now? (y/n)`
   - تمر عليك كل مشكلة وحدة وحدة: `y` نظّف، `n` تخطَّ، `a` نظّف الكل، `q` وقّف.
   - أو شغّل **`Clean.bat`** مباشرة.
4. سوِّ ريستارت للجهاز، وبعدها شغّل `Scan.bat` مرة ثانية وتأكد إن ما فيه `High`.

### إذا ملفات FiveM أو الألعاب في مكان ثاني (مثلاً D:)

افتح PowerShell كمسؤول (Administrator) وشغّل:

```powershell
cd "مسار مجلد security-cleaner"
powershell -ExecutionPolicy Bypass -File .\Scan-And-Clean.ps1 -ScanPaths "D:\Games","D:\FiveM-Server"
```

وإذا تبي فحص كامل للجهاز (أبطأ بس أدق) أضف `-FullScan`.

## وش تفحص الأداة؟

| الفحص | ليش مهم |
|---|---|
| Windows Defender: شغال؟ فيه استثناءات؟ | الفيروسات تطفي الحماية أو تضيف استثناء عشان Defender ما يشوفها |
| سجل تهديدات Defender | يطلع لك أي فيروس انمسك قبل، أو فيروس أنت سويت له "Allow" |
| برامج بدء التشغيل (Run keys، Startup، المهام المجدولة، الخدمات، WMI) | هنا يثبّت الفيروس نفسه عشان يرجع يشتغل كل ما تشغّل الجهاز |
| ملف hosts والبروكسي | لحجب مواقع مكافحة الفيروسات أو للتجسس على اتصالك |
| برامج غير موقّعة في AppData و Temp و ProgramData | المكان المعتاد لسارقات الباسوردات |
| برامج من هالمجلدات متصلة بالإنترنت الحين | ممكن تكون ترسل بياناتك الحين |
| مجلد Steam | ملفات `hid.dll` و `xinput1_4.dll` وغيرها من SteamTools أو GreenLuma أو فيروس |
| FiveM | إضافات مدسوسة في `FiveM.app\plugins`، وسكربتات `.lua` / `.js` فيها باك دور (زي Cipher) تحمّل كود من النت وتشغّله |

## شرح مستويات الخطورة

- **High**: خطير على الأغلب. نظّفه.
- **Medium**: مشبوه. شوفه، وإذا ما تعرفه نظّفه.
- **Info**: للعلم بس، والأداة ما تلمسه.

## التنظيف آمن وتقدر ترجّعه

- الأداة ما تحذف الملفات، تنقلها إلى `C:\SecurityCleaner\Quarantine\التاريخ\`.
- قبل أي تعديل في الريجستري تاخذ نسخة احتياطية `.reg`.
- إذا تخرب شيء (مثلاً سكربت FiveM كان سليم)، شغّل **`Restore.bat`** وترجّع اللي تبيه.
- في ملفات FiveM، التقرير يعطيك **رقم السطر** المشبوه. تقدر بدل الحجر تفتح الملف وتحذف السطر هذا بس.

## ⚠️ مهم جداً بعد التنظيف

الألعاب المكركة و"Steam Tools" المزيفة غالباً فيها **سارق باسوردات (Stealer)**. هذا النوع يسرق حساباتك أول ما يشتغل، والتنظيف ما يرجّع اللي انسرق. عشان كذا:

1. من **جهاز ثاني نظيف** (الجوال مثلاً) غيّر باسوردات: الإيميل، Discord، Steam، Rockstar/CFX، والبنك.
2. سوِّ تسجيل خروج من كل الأجهزة، وفعّل التحقق بخطوتين (2FA).
3. في Steam: Manage Steam Guard ← Deauthorize all other devices.
4. إذا عندك محافظ كريبتو على الجهاز، انقل فلوسك لمحفظة جديدة.
5. إذا رجعت نتائج **High** بعد التنظيف والريستارت، خذ نسخة من ملفاتك وسوِّ **Reset this PC ← Remove everything**. بعد فيروس من نوع RAT أو Stealer، هذا الحل الوحيد اللي يضمن الجهاز نظيف 100%.

للاطمئنان أكثر، تقدر تفحص فحص ثاني بأداة مجانية مثل **Malwarebytes** أو **ESET Online Scanner**.
