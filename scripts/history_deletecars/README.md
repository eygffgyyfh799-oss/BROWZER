# history_deletecars — سكربت حذف السيارات (FiveM)

## التركيب
1. انسخ مجلد `history_deletecars` إلى مجلد `resources` في السيرفر.
2. ضيف في `server.cfg`:
   ```
   ensure history_deletecars
   add_ace group.admin history.deletecars allow
   ```
3. لازم يكون **OneSync** مفعّل.

## الأوامر (للإدارة فقط)
| الأمر | الوظيفة |
|---|---|
| `/dv` | يحذف السيارة اللي راكبها، أو السيارات الفاضية حولك (5 متر) |
| `/dv 20` | يحذف السيارات الفاضية في مسافة 20 متر |
| `/dvall` | يحذف كل السيارات الفاضية في السيرفر بعد عد تنازلي وتنبيهات |
| `/dvall now` | حذف فوري بدون عد تنازلي |

## الحذف التلقائي
كل 30 دقيقة (تقدر تغيرها من `config.lua`) يحذف السيارات الفاضية مع تنبيهات
للاعبين قبل 5 دقايق، دقيقة، 30 ثانية، و10 ثواني.

السيارات اللي فيها أحد ما تنحذف، والموديلات في `Config.IgnoredModels` ما تنحذف أبداً.
