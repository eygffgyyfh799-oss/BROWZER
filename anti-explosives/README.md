# anti-explosives — نظام حماية من المتفجرات (FiveM)

يمنع أي شيء متفجر في السيرفر: RPG، قرنيد، قنابل، C4، ألغام، قاذفات...

## وش يسوي
- أول ما ينضاف غرض متفجر لحقيبة اللاعب **ينحذف فوراً** وتجيه **رسالة تحذير** (إشعار + شات + صوت).
- يمنع نقل المتفجرات لحقيبتك من ستاش/سيارة/أرض/لاعب ثاني، ويمنع شراءها وتصنيعها (ox_inventory).
- لو اللاعب ماسك سلاح متفجر (حتى بهكر) ينشال من يده.
- يلغي أي انفجار يسويه لاعب (صاروخ، قرنيد، لاصقة، لغم...).
- لوق بالكونسول + ويب هوك دسكورد اختياري.

## يدعم
`ox_inventory` · `qb-core` · `es_extended (ESX)` — يتعرف عليهم تلقائياً.

## التركيب
1. انسخ مجلد `anti-explosives` إلى `resources`.
2. في `server.cfg` بعد الفريم ورك والانفنتوري:
   ```
   ensure anti-explosives
   ```
3. (اختياري) استثناء الإدارة:
   ```
   add_ace group.admin antiexplosives.bypass allow
   ```

## التعديل
كل شيء في `config.lua`: قائمة الأغراض الممنوعة، الكلمات الممنوعة، الاستثناءات، رسالة التحذير، ويب هوك، وأنواع الانفجارات.
